Python installs now support several indexes, `python.overrides`, and `python.constraints`. A `registries` entry that names `ecosystem: pypi` declares an index. pnpm also reads uv workspace overrides and constraints from `pyproject.toml` [pnpm/pnpm#14945](https://github.com/pnpm/pnpm/issues/14945).
