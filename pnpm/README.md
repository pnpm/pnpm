# pnpm (pacquet)

The [pnpm](https://pnpm.io) CLI is implemented in Rust. `pacquet` is its
in-repository package name; the published CLI and executable are named `pnpm`.

pnpm v11, the TypeScript CLI, is maintained on the `release/11` branch. See
[`../AGENTS.md`](../AGENTS.md#release-lines-and-backports) for how fixes reach it.

See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for development setup, debugging, testing, and benchmarking.
