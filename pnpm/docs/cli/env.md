:::warning Deprecated

`pnpm env` is deprecated but remains available for users accustomed to its name. It accepts the same subcommands and options as [`pnpm runtime`](./runtime.md). `pnpm env use <version>` is an alias for `pnpm runtime set node <version>`.

:::

Use `pnpm env use <version> [-g]` to install Node.js. The `use` subcommand is an alias for `runtime set node`.
