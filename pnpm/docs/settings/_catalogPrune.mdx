### catalog.entries and catalog.unused

Put the default catalog's packages under `catalog.entries` to configure cleanup alongside them. Use `entries: {}` for an empty map. Without `entries`, a key named `unused` refers to a package.

```yaml title="pnpm-workspace.yaml"
catalog:
  unused: prune
  entries:
    example-tool: ^2.0.0
```

`catalog.unused` accepts `ignore` (the default) or `prune`. Pruning covers the default catalog and all named catalogs in `catalogs`. When a file sets both `catalog.unused` and `catalogPrune`, `catalog.unused` wins.

### catalogPrune

* Default: **false**
* Type: **Boolean**

When set to `true`, pnpm will remove unused catalog entries during installation.

`cleanupUnusedCatalogs` is the deprecated spelling of this setting and continues to work; when both are set, `catalogPrune` wins.
